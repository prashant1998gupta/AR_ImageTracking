Add Player to Leaderboard

Inserts a finished, verified run directly — it appears on the public leaderboard and live feed instantly. Leave phone empty to auto-generate one starting with 00 (impossible for a real number, so seeded rows are easy to spot and Remove later). Do not type a real person's phone number — it would block them from playing until this row is Removed. Also leave the seeded row's ✓ Verified button alone: switching it off can hide the entry as SUSPECT.

Targets — Open / Close

Close a target (poster damaged, area blocked…) and it is skipped for all players instantly — hidden from their chips, not required to finish, counter becomes x/(open count). Nothing is deleted: scans already made stay saved, so re-opening restores everyone's credit. Players holding all remaining targets finish automatically with their last scan as the finish time.

Poster list (from Unity)

The ids must match the AR build exactly — a mismatch is silent: the meme plays but the scan is rejected and the chip never ticks. In Unity run Tools ▸ Meme Hunt ▸ 3. Copy Poster List JSON, then paste the JSON here. Leave this empty (or use "Reset to built-in") to keep the server's built-in list.
